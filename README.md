# VORTEX — игровой сайт

Мини-игры, валюта V-Coins (виртуальная, без реальных денег и ставок), магазин, задания, рейтинг, профили, админ-панель.
Чистый HTML/CSS/JS, готов для GitHub Pages.

## Файлы
`index.html` · `style.css` · `script.js` (сайт) · `api.js` (слой данных) · `admin.html` + `admin.js` (админка) · `config.js` (ключи Supabase) · `supabase.sql` (база, RLS и серверные функции)

## Режимы
- **Локальный прототип** (по умолчанию, `config.js` пуст): всё хранится в localStorage браузера. Первый зарегистрированный аккаунт становится админом. Это только для проверки — общего рейтинга и защиты от подделки нет.
- **Supabase** (боевой): общие аккаунты, рейтинг, админка с серверной проверкой.

## Подключение Supabase
1. Создай проект на supabase.com.
2. **Authentication → Providers → Email**: выключи «Confirm email» (ники превращаются в служебные адреса `ник@vortex-game.app`).
3. **SQL Editor**: вставь `supabase.sql` целиком → Run.
4. **Project Settings → API**: скопируй `Project URL` и ключ `anon public` в `config.js`. Ключ `service_role` НЕ копируй никуда.
5. Зарегистрируйся на сайте и в SQL Editor выполни: `update profiles set is_admin=true where nick='твой_ник';` — после этого появится кнопка «Админ».

## Безопасность
- anon-ключ публичен по дизайну; данные защищены RLS: клиент может только читать, вся запись идёт через функции `security definer`.
- Права администратора проверяются в SQL (`is_admin()`), пароля админа в JS нет.
- Награда за игру ограничена сервером (коэффициент и максимум на игру), но очки считает браузер. Для полной защиты от читеров логику игр нужно переносить на сервер (Edge Functions).
