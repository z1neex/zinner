# Zinner — первая демонстрационная версия

## Что уже работает
- Адаптивный сайт с четырьмя вкладками: Чаты, NFT, Биржа, Профиль.
- Поиск по демонстрационному списку чатов.
- Три изображения NFT из первой коллекции.
- Демонстрационный баланс ZNX и кнопки-покупки.
- PAP-001 показан как личная копия создателя.

## Важно
Это frontend-прототип. Чаты пока демонстрационные; регистрации, общей базы данных, реальной синхронизации между 50 пользователями, настоящего NFT-блокчейна и денежных операций пока нет. Баланс меняется только в текущей вкладке и сбрасывается при перезагрузке.

## Как посмотреть на компьютере
Откройте `index.html` в браузере.

## Как опубликовать бесплатно на Cloudflare Pages
1. Распакуйте архив `zinner_site.zip`.
2. Войдите в Cloudflare и откройте Workers & Pages.
3. Нажмите Create application → Pages → Upload assets (Direct Upload).
4. Назовите проект, например `zinner`.
5. Загрузите содержимое папки `zinner_site` (именно `index.html` и папку `assets`, а не zip-файл, если интерфейс просит файлы/папку).
6. Нажмите Deploy. Cloudflare выдаст адрес вида `https://zinner.pages.dev`.

Для публикации через GitHub можно вместо этого создать репозиторий, загрузить файлы и подключить его в Cloudflare Pages.
